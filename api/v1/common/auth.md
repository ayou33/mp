# 鉴权约定

- **阶段一(当前设计)**:单用户 / 匿名。请求可省略鉴权头;backend-server 用 `X-User-Id` 请求头隔离用户数据(缺省为默认用户),便于本地多环境并存。
- **阶段二(账号接入)**:`Authorization: Bearer <JWT>`;用户数据按令牌身份读写。

## 头字段

| 头 | 阶段 | 说明 |
| --- | --- | --- |
| `Authorization: Bearer <token>` | 二 | 用户身份令牌 |
| `X-User-Id` | 一 | 本地用户标识(可选,缺省默认用户) |

## 规则

- 行情/指标只读接口:鉴权可选(公开数据)。
- 自选/浏览/公式/配置/设置/画线:按用户隔离。
- 401 响应:`common/error.md` 的 `UNAUTHORIZED`。
