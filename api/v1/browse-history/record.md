# POST /api/v1/browse-history

记录一次浏览(用户主动浏览:搜索 / 侧栏点击;初始加载与切周期不记录)。去重置顶,上限 30,超限丢弃最旧。

## 请求

```json
{ "code": "sh600519", "name": "贵州茅台" }
```

| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `code` | string | 是 | 规范化代码或 6 位数字 |
| `name` | string | 否 | 缺省由服务端解析 |

## 响应 201

`BrowseEntry`:

```json
{ "code": "sh600519", "name": "贵州茅台", "viewedAt": "2026-08-11T10:00:00Z" }
```

## 错误

- 404 `NOT_FOUND`:代码无法识别。
